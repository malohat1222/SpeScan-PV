# GitHub'da SpeScan hujjatlarini yangilash

Bu paket **mavjud firmware kodini almashtirmaydi**. Undagi `README.md`, `docs/` fayllari va `assets/spescan-logo.png` GitHub'ga yuklash uchun tayyorlangan.

## GitHub veb-sahifasida yangilash

1. Repozitoriyga o'z GitHub hisobingiz bilan kiring: https://github.com/malohat1222/SpeScan-PV
2. `README.md` faylini oching va qalam (Edit) tugmasini bosing.
3. Shu paketdagi `README.md` matnini joylang. Pastda **Commit changes** tugmasini bosing.
4. `docs` papkasiga uchta **yangi** hujjatni (`OPTICAL_DESIGN.md`, `VALIDATION_PLAN.md`, `ROADMAP.md`) hamda `UPDATE_GUIDE_UZ.md`ni yuklang. Mavjud `WIRING.md` va `CALIBRATION.md`ni manbasini ko'rmasdan o'chirmang yoki almashtirmang.
5. `assets` papkasiga `spescan-logo.png` rasmini yuklang (GitHub 'Add file' → 'Upload files').
6. Repo bosh sahifasini yangilang; logotip, Mermaid sxema va barcha havolalar to'g'ri chiqishini tekshiring.

## Muhim

- Eski README'dagi **1000 W lampa** matni hozir rejalashtirilgan **12 V / 100 W** galogen lampaga mos emas. Bu yangilanishda uskunaning **rejalashtirilgan** varianti yozildi. Bu yig'ilgan qurilma degani emas.
- Firmware nominal 400–1100 nm scan qilishi mumkinligi aytilgan, ammo real optik diapazon kalibrlanmagan.
- Kodga hech qanday yashirin yoki tekshirilmagan o'zgartirish kiritilmadi.
- Agar README'ni yangilagandan keyin Qurilma kodi va hujjat nomlari farq qilsa, ishni boshlashdan oldin haqiqiy komponentlar va `WIRING.md` bilan taqqoslang.
- Patent va DGU bo'yicha da'volar ushbu yangilangan READMEga kiritilmadi.
